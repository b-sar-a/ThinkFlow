# Запуск ThinkFlow: что сделать и в каком порядке

Код готов и лежит в `main`. Чтобы всё заработало «как задумано», нужны четыре настройки в Vercel и Firebase, которые может сделать только владелец проекта. Ниже шаги по порядку. После каждого шага есть проверка: что должно получиться.

Состояние сервера в любой момент видно в **Админке → Состояние** (читает `/api/health`).

## 1. Ключ сервера Firebase (`FIREBASE_SERVICE_ACCOUNT`)

1. Firebase console → проект `gen-lang-client-0029250191` → ⚙ Project settings → **Service accounts** → **Generate new private key**. Скачается JSON-файл.
2. Откройте файл и скопируйте всё содержимое в **одну строку** (или закодируйте в base64).
3. Vercel → проект `think-flow` → Settings → **Environment Variables** → добавьте `FIREBASE_SERVICE_ACCOUNT` (Production). Вставьте строку.
4. Vercel → Deployments → у последнего деплоя меню ⋯ → **Redeploy**.
5. Удалите скачанный JSON-файл с компьютера. Никогда не кладите его в репозиторий.

**Проверка:** Админка → Состояние: «Квота токенов» и всё ниже стало зелёным.

## 3. Индекс Firestore (для удаления комментариев)

Firebase console → Firestore → выберите базу `ai-studio-40c22e6e-5fc3-462c-ad48-ab8924415ba7` → **Indexes** → вкладка **Single field** → **Add exemption**:

- Collection ID: `comments`
- Field path: `userId`
- Включите **Collection group**, порядок Ascending → Save.

Без него удаление аккаунта удалит всё остальное, но комментарии ученика под чужими постами останутся (сервер напишет об этом в лог).

## 4. Правила Firestore (публиковать последним)

1. Firebase console → Firestore → база `ai-studio-40c22e6e-…` → **Rules**.
2. Вставьте содержимое файла `firestore.rules` из репозитория → **Publish**.

Публикуйте только после шага 1 и после проверки, что сайт работает: правила строже прежних (профили учеников закрыты для других учеников, чужие данные читать нельзя). Публичные карточки в сообществе появятся, когда каждый ученик откроет приложение один раз.

Правила я не мог проверить на эмуляторе (нужна Java 21), только прочитал. После публикации пройдите сценарии из шага 6.

## 5. Ваш аккаунт администратора

Админ определяется полем `role = admin` в документе `users/<ваш uid>`, а также списком почт-владельцев в `firestore.rules` и `src/context/AuthContext.tsx` (сейчас в нём две почты, включая вашу `sarvarkhotamov10@gmail.com`). Для почты из списка вход с подтверждённой почтой сразу даёт права админа, но правила нужно опубликовать (шаг 4). Если вы входите с другой почтой, сделайте так:

1. Зарегистрируйтесь на сайте своим аккаунтом.
2. Firebase console → Firestore → коллекция `users` → документ с вашим uid → поле `role` → значение `admin`.

**Проверка:** в боковом меню появился пункт «Админка».

## 6. Ручной прогон на тестовых аккаунтах (один раз)

Нужны три тестовых аккаунта: «админ» (ваш), «учитель», «ученик». Лучше три разных браузера или режима инкогнито.

**Родитель:** ученик → Настройки → «Родители и учителя» → «Создать код». Родитель (другой аккаунт) → «Кабинет родителя» → вводит код → видит ученика. Ученик отзывает доступ → у родителя ученик исчез.

**Учитель:** «Учитель» → Настройки → «Я учитель: открыть кабинет» → заявка. Админ → Админка → Учителя → Подтвердить. Учитель создаёт класс, копирует код. Ученик вводит код в Настройки → «Класс учителя». Учитель видит ученика в классе.

**Удаление:** тестовый ученик → Настройки → Аккаунт → Удалить аккаунт → ввести `DELETE`. Вход должен пропасть; в Firestore не остаётся его документов (кроме жалоб).

**Промокод и приглашение:** Бонусы → код `STARTAI` → «+5000 токенов». Приглашение по ссылке нового ученика → оба получают бонус.

## 6а. Свой домен и превью ссылок

Когда у сайта будет свой домен: Vercel → Settings → Domains → добавьте его, затем Environment Variables → `SITE_URL` = `https://ваш-домен` → Redeploy. От этой переменной зависят картинка и адрес в превью ссылок (Telegram, WhatsApp, соцсети). Пока переменной нет, используется адрес `https://mussthinkflow.vercel.app`. Картинка лежит в `public/og.jpg` (1200×630).

## 7. Юридическое

Если ученикам может быть меньше 13–14 лет, в вашей стране может требоваться согласие родителей на хранение данных и на доступ учителя/родителя к прогрессу. Проверьте это до запуска. Тексты политики приватности (в приложении) описывают, что мы храним и как удалить аккаунт.

## Если что-то не работает

- **Админка → Состояние** покажет, что выключено и что сделать.
- Любой `/api/*` отвечает 500 → откройте `https://<сайт>/api/health`: ответ `API_START_FAILED` содержит причину.
- Логи: Vercel → Deployments → последний деплой → **Functions / Logs**.
